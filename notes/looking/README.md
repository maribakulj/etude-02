# Looking notes (S3)

One file per emblem, named by its 1531 id (A31b…). Each note: the text (motto, gist of the
epigram), what each core edition's woodcut shows (looked at, not inferred), what the text says
that the image cannot, what the image fixes that the text left open, drift across editions, and
what Glasgow's alt-text and Iconclass "image"/"text" keep. Links go to Alciato at Glasgow.

Images are never committed; regenerate side-by-side sheets with
`uv run python scripts/contact.py <id>` (→ `data/derived/contact/`).

Preliminary observations are marked *(prelim.)* until the four core editions have been seen.
