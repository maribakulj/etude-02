# Stage A pilot — report of the blind describer (model instance, anonymised pictures)

79 pictures (20 development emblems × available programmes, shuffled), 855 items: 602 clear,
197 probable, 56 indeterminate. Only the anonymised image files were opened; no web access.

**Blindness failed.** A RECOGNISED line was written for 78/79 pictures (13 clear, 46 probable, 19
indeterminate); about 55 named an Alciato emblem. Recognition came from the motif and spread
because the same subject recurred in 3–7 variants; it then shaped descriptions ("razor",
"remora", "dead lion"). Order effects: two readings were revised after later pictures.

**Ambiguous types.** ACTION vs RELATION (twines round, sits on, rests on; postures); ATTRIBUTE vs
ENTITY for owned objects (crown on a bird, device on a shield); gestures carry interpretation
("tears her hair" vs "hands to head"); SETTING vs ENTITY for background buildings. Counting small
things at 500 px is guesswork. "Empty" coded as ATTRIBUTE.

**Suggestions.** One variant per subject per describer (or mixed subjects), collect RECOGNISED
first plus a "described differently because of recognition?" flag, add POSE, entity ids for
cross-reference, a counting rule (exact ≤ 5, else several/many), a zoom tool.
