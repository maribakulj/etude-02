# Collation of the two Steyner 1531 editions (PROTOCOL §0.1)

A31a (Augsburg, 28 Feb. 1531) vs A31b (6 Apr. 1531), all 104 emblems, by
`scripts/collate_1531.py` (difference hash on the picturae + token similarity of texts), with a
visual check of the most distant pairs (A31b001, 004, 046: same blocks, differences come from the
scanned copies and crops).

- **Woodcuts.** Both editions have picturae for the same 98 emblems (none for 087, 089, 101–104),
  and **every pictura is printed from the same block in both** (65 pairs within the automatic
  threshold; the 33 above it checked on the most distant ones — same blocks).
- **Count reconciled.** 98 picturae but **97 distinct blocks**: the cut of *In simulachrum spei*
  (A31b078) is reused for *Illicitum non sperandum* (A31b013), as Tung states (Variorum no. 46).
  This matches Glasgow's count (97). Tung's 96 is not yet explained.
- **Text.** Type was reset between the two editions: mottos are broken differently (18 emblems)
  and 31 epigrams differ slightly (token similarity 0.92–0.98: spelling, punctuation, a few word
  forms).
- **Decision.** The panel keeps **A31b** (same blocks as A31a; Glasgow's main 1531 edition for
  translations and Iconclass). Text-level coding uses A31b's printed text, with A31a variants
  noted where a unit depends on them.
