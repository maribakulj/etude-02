# Data, provenance and reproduction

## Published artifacts

| Path | Content and provenance |
|---|---|
| `data/ids.csv` | Edition identifiers, positions, presence of pictures, indexing counts and concordance links for the fetched core and 1531 collation editions. Additional full-run downloads do not extend this file. |
| `data/source_manifest.csv` | Relative paths, byte sizes and SHA-256 checksums of the downloaded source cache at publication preparation. No source contents. |
| `data/copy_seeds.csv`, `data/copy_matrix_firstpass.csv` | Earlier machine-generated relation tables; provisional and superseded for the v0.5 experiments. |
| `annotations/pilot/` | Machine-produced form-testing annotations; `blind_map.csv` links anonymised picture ids to edition records. |
| `annotations/pilot_v05/`, `annotations/v05_full/` | Machine-extracted readings of Tung's documented relations, including attributed evidence excerpts. Human verification is pending. |
| `results/pilot_v05/`, `results/v05_full/` | Saved per-query attribution and orientation scores. |
| `results/probes/` | Outputs of the early vision-language probe pipeline test. These do not establish the proposed text–image hypotheses. |
| `results/collation_1531.csv` | Computed image-hash and text-similarity comparisons between A31a and A31b. Hash differences alone do not establish different blocks. |
| `results/logs/` | Preserved execution summaries and fetch logs, with the local user path removed. |

The [full-run report](../notes/v05_full.md) records the evaluated witnesses, exclusions, metrics
and limitations. Earlier pilot files remain available to document how the project developed.
Their presence does not mean their labels or methods are validated.

## Source material kept outside git

`data/raw/` contains Glasgow HTML and woodcut downloads, plus Tung's PDFs and extracted text.
`data/corpus.jsonl` assembles source transcriptions and descriptions. `data/derived/` contains
image contact sheets, crops and intermediate evidence exports containing longer source passages.
These files are excluded under the project's redistribution policy; see [NOTICE.md](../NOTICE.md)
and Glasgow's [copyright and reproduction statement](https://www.emblems.arts.gla.ac.uk/#copyright).
Python environments and tool caches are also excluded.

The published source manifest allows a locally held file to be checked against the version used
here. It is an inventory, not a claim that all 22 Glasgow editions have been downloaded or that
every cached image entered an evaluation. Later downloads can differ if the source site changes.

## Rebuild the image and text cache

From the repository root, with Python 3.11 or later and `uv` installed:

```sh
uv sync --locked
uv run python scripts/fetch_core.py
uv run python scripts/fetch_ids.py A56a A51a A67a A91a
```

For the 1531 collation, also run:

```sh
uv run python scripts/fetch_core.py A31a
uv run python scripts/collate_1531.py
```

The collation script writes a fresh result under `data/derived/`; the published snapshot is
`results/collation_1531.csv`. Fetching uses the existing cache and a minimum three-second request
interval. The scripts download source material for local use; they do not confer redistribution
permission. Early source downloads can take over an hour.

## Evaluate the existing v0.5 relation tables

```sh
uv run python scripts/pilot_v05.py
uv run python scripts/run_v05_full.py
```

These scripts use the published relation tables and cached Glasgow images; they do not need the
Tung PDFs. The first model load downloads `facebook/dinov2-base` from Hugging Face. This is a
substantial CPU workload. The scripts overwrite the corresponding result CSVs. The lockfile
records the Python dependencies, but the current scripts do not pin a model revision or every
source of numerical randomness: bit-for-bit reproduction of the saved scores is not guaranteed.

To revisit the source interpretation, obtain Tung's PDFs through the
[Variorum index](https://www.emblems.arts.gla.ac.uk/alciato/tung-variorum-index.php).
Earlier rule-based seed extraction expects local `.comm` text files under
`data/raw/tung/tungtxt/`; there is no automated PDF-to-commentary extraction pipeline in this
repository. The v0.5 tables were produced by machine reading, not regenerated by the seed rules.

## Verify and refresh the source inventory

```sh
uv run python scripts/source_manifest.py
```

This refreshes `data/source_manifest.csv` from the local raw cache without downloading anything.
Use git to inspect differences against the published inventory before retaining an update.
