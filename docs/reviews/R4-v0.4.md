# Review round 4 (2026-10-13), on PROBLEM v0.4 — two subagent reviewers

## Computer vision reviewer — not yet well-posed; fix 1–4 before code

1. BLOCKING — the 5 classes do not exist in the labels. The first pass has no `same_block` and no
   same-direction copy; `free_copy` is a catch-all (46 % of rows). Re-extract with
   {dependency} × {orientation} × {fidelity}; merge or drop cells with < ~30 high-confidence pairs.
2. BLOCKING — positives and negatives. Task = **within-emblem ancestor attribution** (rank earlier
   cuts of the same emblem; chance 1/k reported). Second, harder setting: corpus retrieval with
   same-emblem independent designs as hard negatives.
3. BLOCKING — RQ4 not identifiable (copies inherit the predecessor's rendering of the text; new
   designs are far from the predecessor by construction; open-vocabulary detection on woodcuts is
   too noisy). Restrict it to new designs and to human-coded entity presence, or make it exploratory.
4. BLOCKING — prose-derived, noisy ground truth; model-vs-model checking is circular. Two
   extractions + human adjudication on ≥ 100 edges, κ per field, headline on adjudicated
   high-confidence edges.
5. Mirror retrieval is trivial (score max over flipped query). The real task is **direction
   inference** (reversed vs same-direction given dependency): flip-augmented features may fail
   (cf. Telling Left from Right), asymmetric dense matching may succeed.
6. Leakage: style of a programme or workshop may drive similarity. Merge witnesses that share
   blocks; never retrieve within the same programme; style-only control.
7. RQ3 at 500 px with pose tools: not measurable. Replace with **human-annotated correspondences**
   on ~40 dependent pairs (5–10 points per pair); PCK for DINOv2/v3, DIFT, MATCHA, SketchFusion.
   This would be a small novel benchmark. Use Gallica scans.
8. Coverage: 21's ancestors run through 77 (A91a, not held locally).

Mandatory baselines:
- edge chamfer/HOG;
- SIFT/VISE + RANSAC ± flip;
- CLIP;
- DINOv2/v3 global;
- dense mutual-NN ± flip;
- SegSwap/ArtMiner if runnable;
- style-only control;
- chance.

Metrics:
- top-1 and MRR (with chance);
- mAP with hard negatives;
- balanced accuracy for direction;
- PCK;
- bootstrap over emblems.

Minimal pilot of about 2 days.

## Humanities reviewer — major revision

1. BLOCKING — Tung's vocabulary does not map onto the classes. "47/83" means "the same cut … with
   minor changes due to re-engraving" (emblem 1), so it can be a recut. Build the typology
   bottom-up from his phrases, with their counts; keep a "Tung-unspecified" class; settle same block
   vs recut on physical evidence (cracks, frame breaks, size).
2. BLOCKING — witness substitutions (47 via 1556, 77 via 1591) are confounds. Each
   (programme, witness) is a dated node; flag edges where the witness postdates the copying event.
3. BLOCKING — the copy graph is open: Wechel 1542, Lyon 1548/49 (origin of 51), de Tournes'
   *Aesopi Phrygis Fabulae*, Reusner 1581, Gesner/Belon, Ovid. Call it "relations between documented
   witnesses"; add 1542 and 1548/49 where available; tag edges naming outside sources.
4. BLOCKING — RQ4 is a false choice. Designers used the epigram (often a vernacular translation),
   commentaries, the previous cut, model books, natural histories and stock. Recast RQ4 as
   **attribution of departures**: for each element added or removed against the previous cut, is
   it licensed by the epigram, by a commentary or translation in that edition, by an outside
   visual source, or by none? Code these departures by hand.
5. BLOCKING — Tung is selective; an unstated pair is never a negative. Estimate his omissions on
   about 50 pairs.
6. Lyon16ci likely covers the 47 and 51 nodes. State the real differences (typing, mirror,
   documented history), and run the demo query. Reproduce Chung 2014 as a baseline.
7. State what humanists gain: a check of Tung; unreported copies in the Aesop, Ovid and Reusner
   corpora; workshop practice quantified.
8. Too many methods: keep 3–4.
9. Human extraction with κ.
